Contar por fotografía

Sube una foto del estante. El sistema encuentra los celulares, reconoce el modelo de cada uno y calcula el inventario. Si la confianza es menor a 70 %, el equipo queda por revisar.

Leer cajas con OCR

Sube imágenes (una por caja) o un documento PDF (una caja por página). El sistema detecta el formato solo, lee el modelo y la línea «CANTIDAD EN CAJA» de cada caja por separado, calcula cantidad × precio y, al confirmar, suma las unidades al stock.
