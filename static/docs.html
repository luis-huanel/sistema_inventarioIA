Cómo conectarse

URL base: http://localhost:5000/api. Si el chatbot corre en otro computador de la misma red, usa la IP de este equipo (por ejemplo http://192.168.1.20:5000/api).

Lo más cómodo para un chatbot: GET /api/contexto devuelve un texto con todo el catálogo y el stock, listo para pegarlo en el prompt; y GET /api/celulares?q=… busca un modelo concreto.
